Sobre o Voicebank

A Tico-Katoua-Blue utiliza gravações CV (Consoante + Vogal) para reproduzir as sílabas japonesas.
Ela foi desenvolvida para ser utilizada principalmente em músicas japonesas e projetos de UTAU/OpenUtau.
em versões futuras ela terá um instalador para utau
